$CONTENT

### Твоя задача

1. Проанализируй запрос пользователя — что нужно отразить в презентации
2. Разбей содержание на слайды (до 10 слайдов)
3. Используй `create_presentation` из `presentation` MCP для создания PPTX
4. Сообщи пользователю S3-ссылку на готовый файл

### Формат слайдов

Каждый слайд: `{ "title": "Заголовок", "content": "Содержание" }`
Содержание можно разделять переводами строк для нескольких пунктов.
